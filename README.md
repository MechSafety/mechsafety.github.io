## 홈페이지 관리

- 홈페이지: https://mechsafety.github.io/
- 관리화면: https://app.pagescms.org/mechsafety/mechsafety.github.io/main/collection/news
- 관리화면에서 `main`을 선택하면 정식 홈페이지 내용을 편집합니다.

### 글과 사진 수정

1. 관리할 메뉴를 선택하고 기존 항목을 열거나 새 항목을 추가합니다.
2. 제목, 내용, 사진 등 해당 칸을 입력합니다. News에는 본문 아래에 사진이 표시됩니다.
3. `홈페이지 공개`를 켜고 Save를 누르면 정식 홈페이지에 자동 반영됩니다. 반영에는 보통 몇 분이 걸립니다.
4. 정식 홈페이지를 새로고침해 결과를 확인합니다. News는 날짜가 최신인 순서로 정렬되며 Home의 Latest News에는 최신 소식 3개가 자동으로 나타납니다.

### News 작성과 사진 관리

- 제목에는 행사명이나 활동명을, 날짜에는 실제 활동 날짜를 입력합니다.
- 글은 본문 한 곳에 작성합니다. 상세 페이지, News 목록과 Home에서 같은 본문을 사용하며 목록에서는 앞부분만 짧게 표시됩니다.
- 사진은 본문에 끼워 넣지 않고 별도 사진 항목에 추가합니다. 사진 개수 제한은 없고, 등록한 순서대로 표시되며 첫 번째 사진이 News와 Home의 대표 사진이 됩니다.
- 홈페이지는 사진의 긴 변을 최대 720px로 맞추고 원본 비율을 유지합니다. 좁은 화면에서는 긴 변도 화면에 맞춰 줄어듭니다. 학생이 사진마다 크기를 지정할 필요는 없습니다.
- 관리 화면의 작은 사진은 선택과 순서 확인용입니다. 홈페이지의 실제 사진 크기와 글 배치는 저장 후 정식 홈페이지에서 확인합니다.
- 외부에서 수정한 내용과 설정 안내가 관리 화면에 바로 보이지 않으면, 작성 중인 내용을 먼저 확인하고 목록에서 글을 다시 열거나 관리 사이트를 새로고침합니다.

Courses의 개설 이력은 과목 안에서 연도와 학기를 추가합니다. Members, Research, Courses는 `표시 순서` 숫자가 작은 항목부터 나옵니다.

저장은 별도의 승인 없이 정식 홈페이지 배포를 시작합니다. 배포 상태는 저장소의 Actions에서 확인할 수 있습니다. 홈페이지 공개를 꺼도 공개 저장소에 저장한 파일과 사진은 비밀 자료가 되지 않으므로, 미공개 연구자료나 개인정보는 올리지 않습니다.

### 관리자와 학생의 계정

교수 계정을 공유하지 않고 담당 학생의 계정으로 관리합니다. Pages CMS의 이메일 협업자 초대 기능을 이용하면 글과 사진을 편집하는 권한을 따로 줄 수 있습니다. 초대 대상은 교수가 지정하며, 담당자가 바뀌면 기존 권한을 회수합니다.

디자인 수정은 별도 작업에서 검토한 뒤 반영하고, 평소 글과 사진 수정에는 Configuration을 변경할 필요가 없습니다. 논문 목록은 Pages CMS의 Publications에서 관리하며, 원래 양식에 포함된 예시 논문 자동 수집은 정기 실행하지 않습니다.
